# Site Bruna Batista

Primeira estrutura do site em Next.js + React + Tailwind CSS.

## Antes de publicar

1. Coloque a foto real enviada pela Bruna em `public/bruna.jpg`.
2. Substitua o número do CRP pelo número confirmado.
3. Configure o número real do WhatsApp nos links de agendamento.
4. Confirme o @ do Instagram.
5. Só publique depoimentos com autorização.

## Rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

A estrutura usa o App Router do Next.js e Tailwind CSS via PostCSS.
